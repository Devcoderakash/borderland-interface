# Borderland Interface

MASTER PROMPT — BUILD THE COMPLETE HACKATHON WEBSITE

Build a production-quality, highly immersive hackathon website called:

🃏 BORDER//LAND

Where Code Meets Survival

This is a technology hackathon inspired by the atmosphere and game mechanics of Japanese survival-thriller stories, especially the concepts of mysterious games, playing-card symbolism, strategy, intelligence, teamwork, risk, and survival.

IMPORTANT:

Do NOT copy Netflix's Alice in Borderland website.

Do NOT use copyrighted character images, logos, screenshots, or exact UI from the series.

The website should have an ORIGINAL visual identity inspired by the concepts of cards, games, survival, mystery, technology, and a parallel digital world.

The experience should feel cinematic, futuristic, mysterious, premium, and slightly unsettling.

The website must still look like a legitimate professional technology hackathon website.
